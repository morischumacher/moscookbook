# iOS Shortcut: Save To Moscookbook

`Save-To-Moscookbook.shortcut` is generated by `node scripts/build-shortcut.mjs`
(`--url` for another address). From the share sheet it sends the shared link
and the three latest screenshots, each as `<time taken>|<base64 JPEG>`; the
server keeps only screenshots from the last few minutes (`imagesFrom` in
`src/lib/captureInput.ts`). The capture key is asked for on import.

The file is unsigned, and iOS imports only signed shortcuts. On a Mac:

```sh
shortcuts sign -m anyone -i Save-To-Moscookbook.shortcut -o "Save To Moscookbook.shortcut"
```

The output file's name becomes the shortcut's name. AirDrop it to the phone.
